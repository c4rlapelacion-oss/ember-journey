# EMBER Journey

A separate QR-and-reflection application for the eight Christian Life Program talks.

## Features

- Scan-first QR flow
- Username/password login
- Seven progressive flame reveals
- Cross appears only after Talk 8
- Talk-specific reflection prompts
- Bible-based encouragement
- Personal journey summary
- Editable user profile
- Admin-created participant accounts
- QR generation restricted to Admins
- Supabase shared database
- Vercel-ready React/Vite deployment

## Admin credentials shown in the app

- `jesember` / `ember`
- `cassyember` / `ember`

During Supabase setup, create their Auth passwords as `ember#E8`. The app automatically transforms the visible password `ember` before authenticating.
